# Find the example code

Open the folder that matches the URL. Start with demo.jsx. Read README.md for the lesson. page.jsx connects the example to Next.js and the shared tabs. lesson.js contains the on-screen explanation. The shared folders start with an underscore and do not create routes.

Examples deliberately repeat a small amount of code so each stage is easy to read. Use named functions for events and callbacks. Use named exports for reusable code. Next.js page, layout, loading, and not-found files use required default exports.
