# Design and brand vocabulary

## Hierarchy and contrast

Hierarchy is the order in which information draws attention. Contrast is a visible difference in color, size, weight, or shape. Use both to support the task.

```jsx
// Main title: strong emphasis
// Supporting details: quieter emphasis
// Main action: easy to find
```

## Alignment and proximity

Alignment gives elements a shared edge or line. Proximity means related things sit near each other. Both can explain groups without extra borders.

```jsx
<div className="space-y-2">Title and related details</div>
```

## Editorial, playful, calm, and technical

These are starting words, not strict rules. Editorial might use strong type and simple rules. Playful might use lively shapes. Calm might use generous space. Technical might use precise alignment and data labels.
