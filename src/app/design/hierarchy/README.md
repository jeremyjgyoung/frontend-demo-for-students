# Hierarchy and grouping

Use emphasis and spacing to show what matters and what belongs together.

## Try it

1. Compare both versions.
2. Say what you notice first and why.

## How it works

### 1. Give elements different jobs

When every line has the same weight, the reader must work out the order. Make the main title stronger and supporting text quieter. Keep semantic heading levels correct.

```jsx
<h2 className="text-3xl font-semibold tracking-tight">
  A walk beside the water
</h2>
```

### 2. Use space to form groups

Keep related details near each other. A larger gap can separate the details from the action. Do not add a border to every item.

```jsx
<div className="mt-6 border-t pt-5">
  <Button>Join the walk</Button>
</div>
```
