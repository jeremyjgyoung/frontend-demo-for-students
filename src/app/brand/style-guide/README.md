# Create a small style guide

Document the choices people should repeat across a site.

## Try it

1. Find a rule for color, type, spacing, and actions.
2. Describe a new card that would fit this guide.

## How it works

### 1. Document decisions, not just swatches

A guide explains what each choice is for. Include real examples of text, buttons, and content. Keep the guide small enough to maintain.

```jsx
// Primary: main action
// Quiet surface: supporting content
// Positive feedback: words plus a status color
```

### 2. Give useful examples

A label such as Join the walk explains the action better than Submit. Record these language choices alongside visual choices.

```jsx
<Button>Join the walk</Button>
<Button variant="outline">View details</Button>
```

## Try a change

Change one value. Predict what will change. Run the page and explain the result.
